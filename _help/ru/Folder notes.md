# Folder notes
https://github.com/lostpaul/obsidian-folder-notes

Плагин уже настроен. Ничего делать не нужно. Изучать тоже.

По сути плагин просто гарантирует ожидаемое, естественное поведение: вы заходите в каталог — и у него уже есть стартовая заметка (аналог `index.html` для сайтов).

А за кадром плагин создаёт такую стартовую заметку для каждого нового каталога.

В дереве заметок эта заметка не видна. На диске как отдельный файл — есть. Название файла совпадает с названием каталога: `blabla/blabla.md`

Как редактировать такую заметку? Нажимаете на каталог — **всё**, вы на этой заметке. Редактируйте. Ничего специально делать не нужно.
