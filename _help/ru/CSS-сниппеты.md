# CSS-сниппеты

**Да, сложное.**

По умолчанию Obsidian раздражает своим, хм, дизайном.

Всё кривое-косое, цвета жуткие.

Можно выбрать себе [красивую тему,](https://community.obsidian.md/search?type=theme) установить и пользоваться. Особенно рекомендуем тему [Things](https://community.obsidian.md/themes/things).

Но что-то по мелочи раздражать всегда будет.

Для мелких допилок [мы](https://www.nnberg.com) сделали инструмент **[Hacksidian](https://github.com/nnberg-com/hacksidian)**. Там 1500+ рецептов по очень точечным улучшениями внешнего вида и опыта использования Obsidian. Любой можно применить, а если надоест — выключить. Программировать для этого не нужно, всё делает одна кнопка.

Но сейчас **вам не нужен никакой инструмент**. Всё уже настроено (с помощью Hacksidian) через маленькие CSS-файлы — сниппеты. Они лежат в подкаталоге `.obsidian/snippets` в каталоге вашего vault. Вот куда вы его распаковали, туда и идите.

Если захотите пошаманить — меняйте эти [CSS-сниппеты](https://obsidian.md/ru/help/snippets). Можно руками, можно с помощью LLM.
